# SchemaNaut 用户文档

SchemaNaut 借助 schemanaut 帮助你在一个项目中持续完成任务。模型连接、模型默认值和组织权限
只来自全局 ~/.schemanaut/config.toml；项目设置只保存项目 MCP 声明。
