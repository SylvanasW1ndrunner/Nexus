# BetaV0.1.1 终端会话焦点与关闭规则

## 背景

底部终端是数据 IDE 中运行脚本、安装依赖、执行项目命令的核心入口。用户常见操作包括新建终端、分屏终端、点击某个终端后清空或关闭。此前终端服务已经具备真实 shell 读写能力，但渲染端在分屏关闭和焦点选择上仍有细节缺口。

## 本次实现

- 抽出 `resolveTerminalCloseState`，统一处理关闭终端后的活跃终端和分屏终端状态。
- 关闭当前活跃终端时，如果另一个分屏终端还存在，则优先提升该分屏终端为活跃终端。
- 关闭分屏终端时，只退出分屏状态，不改变主活跃终端。
- 关闭最后一个终端时，进入空终端状态，并保留新建终端入口。
- 点击任意终端视图会把该终端设为活跃终端，顶部工具栏的清空、关闭等操作会作用在用户刚聚焦的会话上。

## 用户体验约束

- 终端标题栏负责全局会话操作，终端视图负责命令输入和输出展示。
- 分屏模式下，用户点击哪个终端，哪个终端就是后续工具栏操作目标。
- 关闭终端不能留下失效的 `activeTerminalId` 或 `splitTerminalId`，否则会导致清空、关闭、运行命令目标不明确。

## 测试覆盖

- `terminal-layout.test.ts` 覆盖活跃终端选择和分屏选择。
- 新增关闭活跃终端时提升分屏终端的测试。
- 新增关闭分屏终端时退出分屏的测试。
- 新增关闭最后一个终端后进入空状态的测试。
