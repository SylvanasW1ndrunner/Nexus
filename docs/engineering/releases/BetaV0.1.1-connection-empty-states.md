# BetaV0.1.1 连接与 Schema 空状态优化

## 背景

数据工程师和分析师在新建项目时，可能会先创建本地工作空间，再稍后配置数据库连接。此前左侧连接区在没有连接或没有加载 Schema 时缺少明确状态，用户容易误以为功能没有响应。

## 本次实现

- 连接列表为空时，展示“还没有数据库连接”的引导说明，并保留下方 PostgreSQL 连接表单。
- Schema 区域按业务状态展示不同空状态：
  - 未选择或未创建连接：提示连接数据库后查看结构。
  - 已选择连接但尚未连接：提示点击连接后加载 Schema。
  - 已连接但无可见对象：提示暂无表或视图，并说明可能与权限有关。
- 连接列表中的状态文案改为界面语言本地化展示，避免直接暴露内部状态字符串。

## 设计原则

- 新用户能理解下一步动作，不需要阅读额外说明。
- 不打断现有连接、测试、保存、删除流程。
- 初始只支持 PostgreSQL，但文案保持可扩展，后续可以接入 MySQL 等数据库类型。

## 验收点

- 没有连接时，左侧连接区不再是空列表，而是有明确引导。
- 已保存但未连接时，Schema 区域提示先连接。
- 已连接但没有表或权限不足时，Schema 区域提示暂无可展示对象。
- 中文和英文界面均有完整文案。
