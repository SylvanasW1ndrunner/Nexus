# BetaV0.1.1 中文界面文案回归防护

## 背景

产品默认语言是中文，且当前阶段开发文档和主要验收也以中文为主。终端显示中文时容易受控制台编码影响而误判，因此需要用测试直接验证 `i18n.ts` 返回的真实字符串，确保菜单、设置、项目、终端、账号等高频入口保持可读。

## 本次实现

- 校验 `i18n.ts` 中核心中文文案的真实 UTF-8 内容。
- 扩展 `i18n.test.ts`，覆盖默认中文、英文切换和关键工作台标签。
- 增加关键工作台标签测试，覆盖新建项目、打开项目、IDE 设置、项目设置、终端、插件市场、账密登录、发送验证码。
- 增加乱码模式断言，防止常见错误编码字符进入关键中文标签。

## 用户体验约束

- 默认中文界面必须可读。
- 文件菜单、项目设置、IDE 设置、底部终端、插件市场、账号入口不能出现中英文混杂或乱码。
- 英文模式继续保留，后续英文文档和国际化可以在当前词典结构上扩展。

## 测试覆盖

- `i18n.test.ts` 验证默认语言回退到中文。
- 验证英文切换仍返回英文文案。
- 验证关键中文工作台标签和预期中文一致。
- 验证关键标签不包含常见乱码字符。
