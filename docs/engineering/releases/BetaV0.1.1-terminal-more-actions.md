# BetaV0.1.1 终端更多操作菜单

## 背景

底部终端工具栏此前保留了“更多操作”按钮，但按钮处于禁用状态。对于一个面向数据工程师和分析师的 IDE，工具栏中出现不可用的占位按钮会降低完成度感，也不利于后续扩展终端动作。

## 本次实现

- 新增 `terminal-actions.ts`，集中定义终端更多操作菜单项。
- “更多操作”按钮改为可点击菜单。
- 菜单包含：
  - 新建终端。
  - 拆分终端。
  - 清空当前终端。
  - 关闭当前终端。
  - 最大化或还原底部面板。
- 没有活跃终端时，拆分、清空、关闭会禁用，新建和最大化仍可用。
- 切换到底部结果面板时自动关闭终端菜单。

## 用户体验约束

- 工具栏不保留无功能的占位按钮。
- 菜单动作复用现有终端能力，不引入新的未验证执行路径。
- 菜单启用状态由纯函数管理，便于后续扩展更多终端动作。

## 测试覆盖

- `terminal-actions.test.ts` 覆盖有活跃终端和无活跃终端两种状态。
- 继续复用终端服务和终端布局测试验证新建、关闭、清空和分屏状态。
