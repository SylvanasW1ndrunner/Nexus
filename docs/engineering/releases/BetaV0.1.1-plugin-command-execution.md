# BetaV0.1.1 插件命令执行细化

## 背景

插件市场已经提供官方插件 manifest 和命令贡献点。命令面板会展示已安装、已启用插件的命令，因此这些命令必须尽量连接到真实功能，避免插件机制停留在静态展示层。

## 本次实现

- `dbagent.python.createVenv` 从“打开设置窗口”改为直接调用 Python 环境创建流程，默认创建项目内 `.venv`。
- `dbagent.chart.preview` 继续保持占位能力，但提示改为 i18n 文案，避免命令分发里硬编码中文/英文。
- 未绑定命令的兜底提示改为 i18n 文案，并清理命令分发中的旧乱码字符串。

## 用户体验约束

- 命令面板中出现的官方插件命令应尽量对应真实动作。
- Python 官方插件的创建虚拟环境命令要求已打开项目；启用条件仍由 `isPluginCommandEnabled` 控制。
- 图表预览插件当前仍是官方占位插件，未安装时不会出现在命令面板；安装后执行会提示运行时视图后续接入。

## 测试覆盖

- `i18n.test.ts` 覆盖图表预览提示和未知命令提示的中文文案。
- 继续复用 Python 环境服务测试验证 `.venv` 创建和运行链路。
