# BetaV0.1.1 项目向导与设置弹窗优化

## 背景

项目/工作空间是 BetaV0.1.1 的核心能力入口。用户会通过这里创建项目、选择数据库类型、配置连接、设定 Python 环境和资产目录。此前弹窗右侧表单缺少清晰分段，连接输入也缺少字段标签，整体更像开发调试页。

## 本次实现

- 新建项目向导右侧改为分段卡片：
  - 项目基础信息。
  - 数据库连接。
  - Python 环境。
- 项目基础信息增加显式字段标签，不再只依赖 placeholder。
- 数据库连接表单增加连接名称、主机、端口、数据库、用户名、密码标签。
- 项目设置弹窗增加“项目资产目录”说明区，明确 SQL、脚本、文档和输出目录用途。
- 保持左侧数据库类型选择结构，当前仍只展示 PostgreSQL，为后续 MySQL 等数据库扩展留入口。

## 设计原则

- 新建项目流程参照 JetBrains 类项目向导：左侧类型选择，右侧分段配置。
- 不改变现有 workspace、connection、python draft 数据流。
- Python 环境配置作为数据工程项目的一等配置入口展示。

## 验收点

- 新建项目弹窗能清楚区分项目基础信息、数据库连接和 Python 环境。
- 创建连接时所有数据库字段都有可见标签。
- 项目设置弹窗展示资产目录说明。
- 中英文界面均有完整文案。
