# BetaV0.1.1 登录门禁与终端输入修复记录

## 背景

本轮针对用户验收反馈修复两个问题：

- 登录界面不应展示账号或密码存储位置等内部实现说明。
- 当前版本需要提供测试账号，并且未登录不能进入工作台。
- 终端需要继续按真实系统终端行为验证，尤其是逐字符输入后能正常显示输出。

## 认证调整

- 启动登录弹窗移除关闭按钮，登录成功前不能进入工作台。
- 登录文案改为用户视角说明，不再展示数据库、环境变量或密码存储位置。
- 无认证数据库配置时，主进程启用本地测试账号仓储：
  - 账号：`test`
  - 密码：`test`
- 账密登录允许普通账号名；验证码登录、注册和忘记密码仍要求邮箱或手机号。

## 终端调整

- 前端终端输出轮询改为串行读取，避免定时轮询和按键后即时轮询并发读取同一 cursor，造成输出重复或状态抖动。
- 新增真实 PTY 逐字符输入测试，模拟用户键盘输入 `echo dbagent-char-input` 后读取输出。

## 验证

- `auth-service.test.ts` 覆盖本地测试账号 `test/test` 登录和错误密码拒绝。
- `auth-form.test.ts` 覆盖账密登录允许测试账号，验证码流程仍拒绝非邮箱/手机号。
- `terminal-service.test.ts` 覆盖真实 PTY 逐字符输入、输出读取、工作目录和清屏。
- TypeScript 与 ESLint 均通过。
