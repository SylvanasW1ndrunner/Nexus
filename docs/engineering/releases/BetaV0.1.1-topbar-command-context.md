# BetaV0.1.1 顶部命令栏优化

## 背景

BetaV0.1.1 的主界面正在向 Cursor 类 IDE 工作台靠拢。此前顶部栏只有基础菜单和语言切换，缺少桌面工具常见的当前上下文与高频命令入口，用户需要从左侧、底部状态栏和编辑器区域拼接当前工作状态。

## 本次实现

- 顶部栏增加品牌标识，强化桌面应用识别度。
- 顶部中部保留文件、运行、设置下拉菜单。
- 菜单旁增加命令上下文胶囊：
  - 当前项目。
  - 当前文件。
  - 当前数据库连接。
- 顶部右侧增加高频命令：
  - 保存 SQL。
  - 运行 SQL。
- 语言切换保留在右侧操作区，仍支持中文和英文切换。

## 设计原则

- 顶部栏承担“当前工作区状态”和“高频命令入口”的职责。
- 不改变原有菜单动作，只把常用动作前置。
- 保持 IDE 风格的信息密度，避免做成营销页或大面积装饰。

## 验收点

- 顶部栏显示品牌标识、菜单、项目/文件/连接上下文、高频命令和语言切换。
- 保存 SQL、运行 SQL 顶部按钮复用现有动作。
- 在较窄窗口下，顶部上下文会收缩隐藏连接胶囊，避免挤压命令区。
