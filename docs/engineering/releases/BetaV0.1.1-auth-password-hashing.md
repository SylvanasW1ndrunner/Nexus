# BetaV0.1.1 账号密码哈希增量

## 目标

本轮把账号密码存储从开发级 SHA-256 升级为带随机 salt 的 PBKDF2-SHA256 格式。账号数据仍存储在 PostgreSQL，后续迁移到云端时可以沿用同一字段格式。

## 新格式

密码哈希格式：

```text
pbkdf2-sha256$iterations$salt$hash
```

当前参数：

- `iterations`: 210000
- `salt`: 16 字节随机值，base64url 编码
- `hash`: 32 字节派生值，base64url 编码

## 兼容策略

旧版本曾使用 SHA-256 十六进制字符串。为了避免测试用户账号失效：

- 登录时仍接受旧 SHA-256 哈希。
- 旧哈希登录成功后，会立即写回新 PBKDF2 格式。
- 新注册和重置密码只写入新格式。

## 验证码

短信/邮箱验证码仍使用短期 SHA-256 哈希，因为验证码有效期短且一次消费。生产云端接入短信/邮箱服务后，应继续保证验证码不明文持久化。

## 测试

- 新注册账号密码写入 PBKDF2 格式。
- 密码校验使用 `verifyPassword`。
- 旧 SHA-256 账号可以登录，并在登录后自动升级。
