# BetaV0.1.1 中文资源 UTF-8 重建

## 背景

渲染端中文资源曾出现 UTF-8 被错误解码后的乱码，且测试用例也把乱码作为期望值，导致问题无法被自动测试发现。这会直接影响默认中文界面的一致性和产品观感。

## 本次调整

- 重建 `i18n.ts`，保留英文资源和翻译 API，替换中文资源为正常可读中文。
- 补齐新增文件、文件夹示例、requirements 路径等此前可能回退英文的中文文案。
- 重建 `i18n.test.ts`，断言真实中文文本，并扫描常见乱码片段。

## 验收要点

- 默认中文界面不应出现乱码。
- 核心工作台、终端、认证、命令面板、插件和设置文案应为中文。
- 后续新增中文文案时，测试不能再把乱码作为期望值。
