# BetaV0.1.1 Cursor 式工作台对齐

## 背景

本轮目标是继续收敛工作台形态，使主界面更接近 VS Code / Cursor 的产品结构：左上角是文件与项目入口，左侧是项目文件树，中间是代码编辑器，右侧只承载 Agent 对话。

## 调整内容

- 顶部栏将“文件 / 运行 / 设置”移动到左上角，文件菜单内保留新建项目、打开项目、保存 SQL。
- 右侧栏移除数据库连接表单、快捷问题和查询历史，只保留 Agent 对话框。
- Agent 对话改为简单聊天形态：顶部轻量上下文、消息流、底部输入框。
- 数据库连接管理迁移到“设置 > 项目设置”的分类弹窗中。
- 项目设置弹窗改为 JetBrains 式布局：左侧配置条目，右侧显示对应表单。
- 主题改为接近 VS Code / Cursor 的深色工作台，绿色仅作为 DBAgent 的动作强调色。

## 产品原则

主工作台必须保持稳定的 IDE 心智：

- 左侧只做项目文件定位。
- 中间只做脚本编辑和结果查看。
- 右侧只做自然语言 Agent 对话。
- 配置类能力进入顶部菜单与弹窗，不占用主工作区。

## 验收重点

- 左上角能直接进入新建项目和打开项目。
- 右侧不再出现连接配置、历史列表、快捷问题卡片。
- 项目设置弹窗具备左侧分类导航和右侧配置详情。
- 主界面配色接近 VS Code / Cursor 深色主题。
