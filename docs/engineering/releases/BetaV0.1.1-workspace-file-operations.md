# BetaV0.1.1 工作区文件操作

## 背景

项目文件树不能只读。用户在 IDE 内创建脚本后，需要继续完成重命名、删除和刷新等基础操作，否则会频繁跳出产品到系统文件管理器。

## 实现内容

- 在 shared IPC 契约中新增：
  - `workspace:rename-file`
  - `workspace:delete-file`
- 在主进程 `WorkspaceProjectStore` 中新增：
  - `renameFile`
  - `deleteFile`
- 在左侧文件树中增加文件右键菜单：
  - 打开文件
  - 重命名
  - 删除
- 重命名使用产品内弹窗，不依赖系统 `prompt`。
- 重命名当前打开文件时，会同步更新编辑器标题、相对路径和语言类型。
- 删除当前打开文件时，会清空编辑器并回到默认空白状态。

## 安全边界

文件操作只允许作用于普通文件，不对目录递归删除。所有路径都会经过已有的工作区相对路径规范化逻辑，拒绝：

- 绝对路径。
- `..` 路径逃逸。
- `.dbagent` 等隐藏目录。
- `node_modules`。
- 覆盖已有目标文件。

## 测试覆盖

- 在真实临时工作区写入文件后重命名，并重新读取验证内容未丢失。
- 删除文件后验证无法再次读取。
- 重命名拒绝路径逃逸。
- 重命名拒绝覆盖已有文件。
- 删除拒绝 `.dbagent/workspace.json`。
- IPC channel 契约测试覆盖新增请求/响应映射。
