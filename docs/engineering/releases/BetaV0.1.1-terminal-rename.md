# BetaV0.1.1 终端重命名优化

## 用户场景

数据工程师在同一个项目中通常会同时打开多个终端，例如一个用于 Python ETL 脚本，一个用于数据库迁移命令，一个用于临时依赖安装。默认的 `Terminal 1`、`Terminal 2` 在会话数量增加后可读性不足，因此需要允许用户为当前终端设置业务化名称。

## 实现内容

- 底部终端的更多操作菜单新增“重命名终端”。
- 点击后弹出统一样式的重命名弹窗，支持输入名称并按回车确认。
- 名称会进行首尾空白裁剪，并将连续空白压缩为单个空格。
- 空名称会被拒绝，并在状态区域显示校验提示。
- 重命名结果立即反映在终端标签列表中，不影响当前终端进程和输出内容。

## 边界说明

- 当前版本的终端名称属于运行期 UI 状态，不写入项目配置文件。
- 关闭应用或重新创建终端后，名称仍由终端服务按默认规则生成。
- 后续如需要跨会话恢复，可将终端布局状态纳入工作区 UI 状态存储。

## 测试覆盖

- `terminal-actions.test.ts`：验证终端操作菜单在有/无活动终端时正确启用“重命名终端”。
- `terminal-display.test.ts`：验证终端名称显示优先级与名称规范化逻辑。
- TypeScript 构建会校验新增翻译键与组件回调类型是否完整。
