# BetaV0.1.1 终端面板 VSCode 风格调整

## 背景

用户反馈底部控制台应直接参考 VSCode：顶部是 `PROBLEMS / OUTPUT / DEBUG CONSOLE / TERMINAL / PORTS` 标签，终端工具集中在右上角，主体区域保持干净。

## 本次实现

- 底部面板标签改为 VSCode 风格分组。
- `OUTPUT` 对应查询结果输出，`TERMINAL` 对应终端。
- 终端会话列表和新建、分屏占位、清空、更多、最大化占位、关闭按钮集中到右上角。
- 终端主体改为更接近 VSCode 的深色背景和低边框输入行。
- 命令行保留轻量运行按钮，确保当前非 PTY 实现仍可用。

## 说明

当前终端仍基于持久 shell 进程和输入框写入，不是完整 PTY。后续若接入 `node-pty`，可进一步把输入完全合并到终端缓冲区。
