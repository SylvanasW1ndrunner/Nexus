# BetaV0.1.1 UI 图标细节修正

## 背景

右侧 Agent 顶部按钮、结果导出按钮、结果列筛选按钮此前使用了不稳定字符。Windows 环境或编码显示异常时会渲染为乱码，影响产品质感。

## 本次实现

- 右侧 Agent 顶部保留三个按钮：对话历史、设置、新对话。
- 结果面板保留导出图标按钮，菜单仍提供 CSV、Excel、JSON。
- 结果表格保留列筛选图标按钮。
- 图标改为本地 CSS 绘制，不新增依赖，避免影响桌面端打包体积。

## 后续约束

正式接入图标库时，应优先选择成熟开源库，并统一按钮尺寸、悬浮状态和无障碍标题。当前 CSS 图标只作为 BetaV0.1.1 的轻量稳定方案。
