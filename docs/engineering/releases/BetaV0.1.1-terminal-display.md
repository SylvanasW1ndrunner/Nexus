# BetaV0.1.1 终端标签和状态展示

## 背景

底部终端已经支持新建、关闭、拆分、清空和更多操作，但多个终端标签只显示 shell 名称，用户难以区分会话。终端状态也只有退出码，缺少直观语义。

## 实现内容

- 新增 `terminal-display.ts`，统一终端标签和状态展示规则。
- 终端标签优先显示会话名，例如 `Terminal 1`、`Terminal 2`。
- 状态展示支持：
  - 就绪
  - 运行中
  - 已退出
  - 失败
- 非零退出码会显示为失败状态并附带退出码。

## 测试覆盖

- `terminal-display.test.ts` 覆盖终端标签优先级。
- 覆盖 running、exited、failed、ready 状态和退出码展示。

## 后续优化

- 支持用户重命名终端。
- 支持为不同运行任务自动命名终端，例如 `Python: clean_orders.py`。
- 支持终端任务历史。
