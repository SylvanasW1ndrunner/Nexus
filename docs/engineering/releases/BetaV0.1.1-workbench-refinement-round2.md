# BetaV0.1.1 工作台细化修正第二轮

## 背景

本轮反馈指出当前界面仍存在明显结构问题：

- 系统菜单栏为英文，深色工作台内又重复了一套中文菜单，顶部不协调。
- 无项目状态下仍默认显示 `Scratch.sql`，让用户误以为已有项目脚本。
- 右侧 Agent 对话栏过度照搬参考产品，缺少 DBAgent 自身定位。
- 左右侧栏不能收起或调整宽度。
- 底部结果区缺少 VS Code 式面板切换，未来控制台、多终端、结果视图无法承载。

## 调整内容

- 原生应用菜单改为中文，承载新建项目、打开项目、保存文件、运行 SQL、项目设置和侧栏切换。
- 移除深色工作台内重复的 `文件 / 运行 / 设置` 菜单，只保留快捷保存与运行按钮。
- 无项目时默认进入欢迎/空编辑状态，不再自动出现 `Scratch.sql`。
- 左右侧栏增加收起按钮与拖拽宽度调整。
- 底部结果区升级为面板 Tabs：`结果 / 控制台`。
- 控制台面板预留多终端标签结构，后续接入脚本运行、日志和终端会话。
- 右侧对话栏从 `CODEX` 命名调整为 DBAgent 自有 `AGENT` 定位。

## 验收重点

- 顶部白色系统菜单栏应为中文，且不再与深色工作台菜单重复。
- 未打开项目时，中间编辑区不应显示默认 SQL 脚本。
- 左右侧栏可收起，也可通过分隔条调整宽度。
- 底部面板可在结果和控制台之间切换。
- Agent 右栏保留参考产品交互结构，但文案和定位不再照抄。
