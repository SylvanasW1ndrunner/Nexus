# BetaV0.1.1 插件命令激活规则

## 背景

插件市场已经具备官方插件列表、安装、启用、禁用和命令面板展示能力。但插件命令是否可用的判断此前直接写在 `App.tsx` 中，后续接入第三方插件或扩展官方插件时会让 UI 组件不断堆积命令规则。

## 本次调整

- 新增 `plugin-command.ts`，集中处理插件命令可用性。
- 插件命令判断现在同时考虑：
  - 插件是否已安装并启用。
  - 命令是否由该插件 manifest 贡献。
  - 当前上下文是否匹配数据库、编辑器语言、工作区和结果集状态。
  - `activationEvents` 是否匹配当前 IDE 上下文。
- `App.tsx` 的命令面板改为调用独立插件命令模块。

## 测试

- `plugin-command.test.ts` 覆盖 PostgreSQL、Python Runner、Result Export、Chart Preview 四类官方插件命令。
- 覆盖未安装、未启用、语言不匹配、无工作区、无结果集等不可用状态。

## 后续扩展

第三方插件接入时应继续沿用 manifest 贡献结构，命令执行入口需要在受控命令注册表中显式绑定，避免未实现命令在界面中表现为可执行。
