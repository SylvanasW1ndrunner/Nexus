# BetaV0.1.1 插件市场动作语义修正

## 背景

插件市场是后续官方插件和第三方插件机制的入口。安装、卸载、启用、禁用这些动作会直接改变插件注册状态，前端按钮必须表达“目标状态”，不能把“当前状态”作为参数继续传递，否则后续扩展时容易产生反向调用。

## 本次实现

- 新增 `getPluginPrimaryAction`，统一把插件当前状态转换为 UI 按钮的目标动作。
- 未安装插件的主动作是安装，目标为 `installTarget: true`。
- 已安装插件的安装动作目标为 `installTarget: false`，对应卸载。
- 已启用插件的启用动作目标为 `enableTarget: false`，对应禁用。
- 已安装但未启用插件的启用动作目标为 `enableTarget: true`，对应启用。
- `App.tsx` 中插件 IPC 调用改为按目标状态选择 `install/uninstall` 或 `enable/disable`。

## 用户体验约束

- 按钮文案和实际 IPC 动作必须一致。
- 内置插件仍不能卸载，但可以保留启用/禁用能力，为后续官方插件能力开关预留空间。
- 插件市场搜索、分类、安装状态筛选继续使用同一套插件注册数据。

## 测试覆盖

- `plugin-marketplace.test.ts` 覆盖插件动作目标推导。
- 覆盖已安装启用、已安装未启用、未安装三类用户可见状态。
- 继续复用 `plugin-registry.test.ts` 验证主进程安装、卸载、启用、禁用的持久化行为。
