# BetaV0.1.1 终端与登录体验细化

## 背景

用户测试反馈集中在三个问题：

- 新建终端后，底部终端工具区会和底部面板标签/状态行挤压重叠。
- Windows PTY + xterm 场景下，终端可能把 xterm 自动响应的能力查询序列显示成乱码。
- 登录不应该藏在设置页里，启动应用时应直接弹出登录/注册入口；默认欢迎文案也应减少。

## 实现内容

- 底部面板标题栏改为明确的左侧标签、状态文本、右侧终端工具区域布局。
- 终端会话列表限制宽度并隐藏溢出，避免新增多个终端时压到左侧标签。
- 新增 `terminal-input.ts`，过滤 xterm 自动生成的能力查询/窗口状态响应：
  - 设备能力响应。
  - 窗口状态响应。
  - 光标位置响应。
- 保留普通用户输入、回车、Ctrl+C、方向键等交互控制键。
- 启动应用时检查本地认证状态，未登录时弹出账号登录 modal。
- 登录、验证码登录、注册成功后自动关闭启动登录 modal。
- Agent 面板不再预置欢迎消息，右侧顶部去掉“工作台已就绪”副标题。
- 默认编辑器标题从“欢迎”改为 `Untitled`。

## 测试覆盖

- `terminal-input.test.ts` 覆盖自动响应过滤和真实用户输入保留。
- `terminal-service.test.ts` 继续覆盖真实 PTY 创建、写入、读取、清空和 resize。
- TypeScript 和 ESLint 覆盖启动登录 modal、账号面板回调和终端输入过滤接入。
