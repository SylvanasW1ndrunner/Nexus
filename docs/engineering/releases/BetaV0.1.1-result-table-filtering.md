# BetaV0.1.1 查询结果筛选逻辑加固

## 背景

SQL 查询结果区已经具备搜索框和列筛选入口，但筛选逻辑集中在 React 组件内部，缺少独立测试。此前用户可以取消所有列勾选，随后表格又回退显示全部列，导致菜单状态和表格显示不一致。

## 本次调整

- 新增 `result-table.ts`，抽离结果表列显示、列切换、搜索过滤和单元格格式化逻辑。
- 列筛选现在至少保留一列可见，避免“没有勾选但表格全显示”的不一致状态。
- 搜索逻辑明确只在当前可见列中匹配，更符合用户对列筛选后的结果搜索预期。
- `ResultTable` 组件改为复用纯函数逻辑，降低后续 UI 调整时破坏筛选行为的风险。

## 测试

- `result-table.test.ts` 覆盖：
  - 可见列解析。
  - 最后一列不可取消。
  - 当前可见列内搜索。
  - JSON、空值和字符串单元格格式化。

## 验收要点

- 结果表列筛选菜单中至少保留一列。
- 搜索只匹配当前可见列。
- 切换新查询结果时，搜索和列筛选状态会重置。
