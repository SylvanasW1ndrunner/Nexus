# BetaV0.1.1 命令面板核心命令本地化

## 背景

命令面板是 IDE 高频入口。此前面板本身已经接入中文文案，但核心命令列表仍使用硬编码英文，例如 `New Project`、`Run Current SQL`、`Open IDE Settings`。中文模式下打开命令面板会出现明显中英文混杂。

## 本次实现

- 为核心命令标题新增本地化键：
  - 新建项目、打开项目、保存文件。
  - 运行当前 Python 文件、运行当前 SQL、分析当前 SQL。
  - 打开 IDE 设置、打开项目设置。
  - 切换资源管理器、切换 Agent 面板。
- 为命令分类和来源新增本地化键：文件、设置、视图、核心。
- `buildCommandPaletteItems` 接收翻译函数，核心命令按当前语言生成。
- 命令列表 `useMemo` 增加翻译函数依赖，语言切换后命令面板内容会随之刷新。

## 用户体验约束

- 中文模式下，命令面板核心命令不应显示硬编码英文。
- 插件贡献命令仍来自插件 manifest，后续插件市场需要定义插件本地化字段。
- 核心命令启用条件保持不变，例如 Python 命令仍要求当前文件是 Python 且已打开项目。

## 测试覆盖

- `i18n.test.ts` 覆盖命令面板核心命令中文文案。
- 保留默认中文和英文切换测试。
