# BetaV0.1.1 查询历史检索增强

## 范围

本次切片增强 `core-db` 查询历史能力，不涉及前端 UI。

新增能力：

- 查询历史支持按连接、执行状态、风险级别、语句类型筛选。
- 查询历史支持按 SQL 文本、错误信息和安全原因全文搜索。
- 查询历史支持创建时间范围过滤。
- 新增 `search()` 合同，返回 `items`、`total`、`offset`、`limit`，用于后续历史面板、Agent 读取历史和事故审计。
- `db:query-history` IPC 请求类型扩展筛选字段，响应保持历史数组，兼容现有调用方。

## 安全边界

- 该模块只读取本地历史 JSON，不执行 SQL。
- 不读取、不返回数据库密码或连接密钥。
- 损坏历史文件继续按空历史降级，避免影响应用启动和后续查询执行。

## 测试

已覆盖：

- 成功查询历史按最新优先保存。
- 被拦截 SQL 保留审计上下文。
- 按 SQL 文本、错误信息和安全原因搜索。
- 按连接、状态、风险级别和语句类型组合筛选。
- 分页元数据返回。
- 按时间范围过滤近期执行记录。
- 损坏 JSON 降级为空历史。

## 打包影响

无新增依赖。该切片只修改 TypeScript 业务逻辑和类型合同，不引入 native 模块或额外运行时。
