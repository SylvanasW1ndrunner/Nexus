# BetaV0.1.1 项目侧栏摘要优化

## 背景

BetaV0.1.1 的目标是让产品从简单数据库工具，逐步变成面向数据工程师和分析师的项目工作台。用户会在一个项目中管理 SQL、Python 脚本、文档、输出文件和数据库连接，因此左侧项目区域不能只展示文件树，也需要展示项目运行上下文。

## 本次实现

- 在已打开项目的左侧面板中增加项目摘要卡片：
  - 项目名称和根目录。
  - 项目设置入口。
  - SQL 库目录、脚本目录、输出目录、requirements 路径。
  - Python 环境模式。
  - 当前项目关联连接数量。
- 摘要区采用紧凑两列布局，避免挤占文件树空间。
- Python 环境模式使用界面语言本地化展示，保持后续语言切换一致性。

## 业务价值

- 用户打开项目后，可以立即确认当前工作空间的关键配置。
- 数据处理脚本和 SQL 资产的存放位置更明确。
- 为后续 Python 环境校验、依赖安装、脚本运行器入口预留界面位置。

## 验收点

- 打开项目后，左侧项目区域显示项目摘要，而不是只显示路径和文件树。
- 点击项目摘要中的“项目设置”可以打开项目设置弹窗。
- SQL、脚本、输出、requirements、Python 模式和项目连接数均来自当前项目配置。
- 中英文界面均有完整文案。
