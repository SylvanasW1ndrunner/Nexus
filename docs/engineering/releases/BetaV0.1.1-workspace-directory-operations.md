# BetaV0.1.1 工作区目录操作

## 背景

文件树需要具备目录级基础操作，否则项目内 SQL、Python 脚本和文档无法按真实业务结构组织。本次补齐新建文件夹、目录右键菜单和刷新入口。

## 实现内容

- shared IPC 新增：
  - `workspace:create-directory`
  - `workspace:delete-directory`
- 主进程 `WorkspaceProjectStore` 新增：
  - `createDirectory`
  - `deleteDirectory`
- 左侧 Explorer 标题栏新增：
  - 新建文件
  - 新建文件夹
  - 刷新文件树
- 文件树右键菜单扩展：
  - 文件：打开、重命名、删除。
  - 文件夹：在此新建文件、在此新建文件夹、删除文件夹。
- 新建文件夹使用产品内弹窗，输入项目内相对目录路径。

## 安全边界

- 目录路径必须是工作区内相对路径。
- 拒绝绝对路径、空路径、`..` 逃逸、`.dbagent` 和 `node_modules`。
- 删除目录支持递归删除，但禁止删除顶层工作区骨架目录，例如 `sql`、`scripts`、`docs`、`outputs`。
- 主进程仍是最终安全边界，渲染端校验只用于更好的用户提示。

## 测试覆盖

- 在真实临时工作区创建多级目录。
- 在目录内写入文件后递归删除目录，并验证文件无法再次读取。
- 拒绝删除顶层工作区目录。
- 拒绝路径逃逸目录创建。
- 渲染端目录路径归一化和非法路径拦截。
- IPC contract 覆盖新增目录 channel。

## 后续优化

- 支持目录重命名和拖拽移动。
- 使用更明确的图标库替换文本符号按钮。
- 删除目录时展示影响文件数量，降低误删风险。
