# BetaV0.1.1 工作台侧栏与视觉修正

## 背景

本轮反馈指出左侧项目管理区域仍然承载过多项目摘要、连接状态和最近项目内容，不符合类 Cursor 的文件树心智；同时顶部语言选择和基础控件观感偏粗糙，颜色层级不够一致。

## 调整内容

- 左侧栏收敛为资源管理器：仅保留项目文件树、当前项目名称和根目录提示。
- 移除左侧项目摘要卡、Python 运行时摘要、连接数和最近项目列表。
- 数据库连接管理迁移到右侧辅助区，与助手上下分区展示，左侧不再混入数据库表单。
- 顶部语言选择从原生下拉改为紧凑分段按钮，减少系统控件带来的粗糙感。
- 统一暗色界面的基础色板、边框色、按钮字重和文件节点色彩，减少不协调的高饱和装饰色。

## 产品原则

工作台的左侧栏应优先服务“项目内文件定位与打开”，项目配置和数据库连接属于上下文管理能力，应通过顶部菜单、设置弹窗和右侧辅助区承载。这样可以让数据工程师在编辑 SQL/Python 脚本时拥有更稳定的 IDE 式空间结构。

## 验收重点

- 打开项目后，左侧首屏应主要呈现文件树。
- 左侧不应再出现项目摘要卡片、最近项目列表或连接表单。
- 顶部语言切换控件应与按钮、菜单保持一致的暗色桌面应用风格。
- 文件树选中态、悬浮态和普通态应清晰但克制。
