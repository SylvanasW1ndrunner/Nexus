# BetaV0.1.1 增量记录：工作台状态栏

开发日期：2026-06-08。分支：`BetaV0.1.1`。

## 已实现

- 主工作台底部新增状态栏，固定展示项目、连接、当前文档、语言和保存状态。
- 状态栏会显示当前打开的 Workspace 名称；未打开项目时显示未打开项目。
- 状态栏会显示当前连接名称；未选择连接时显示未选择连接。
- 状态栏会显示当前编辑文档路径或标题、语言类型，以及已保存/未保存状态。
- 有查询结果时，状态栏会展示行数和耗时，便于用户在编辑区和结果区之间快速判断执行反馈。
- 状态栏文案纳入中英文 i18n 字典。

## 验证

已通过：

```bash
pnpm run ci
pnpm --filter @dbagent/desktop build
pnpm --filter @dbagent/desktop exec electron-builder --dir
pnpm package:verify
```

## 设计说明

状态栏是 IDE/数据工具中非常低成本但高识别度的界面元素。它不会替代结果区或项目面板，只承担“全局上下文提示”的角色，让用户始终知道当前操作属于哪个项目、哪个连接和哪个文件。
