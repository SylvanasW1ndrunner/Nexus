# BetaV0.1.1 编辑器与结果区上下文优化

## 背景

BetaV0.1.1 的核心界面参考 Cursor 类 IDE 工作台：左侧项目管理，中间代码编辑器，右侧对话窗口。中间区域是数据工程师和分析师执行 SQL、查看结果、判断风险的主工作区，因此需要更明确的运行上下文和结果反馈。

## 本次实现

- 编辑器顶部增加运行上下文条：
  - 当前文件。
  - 当前连接。
  - 保存状态。
  - 只读连接标记。
- 结果区增加查询结果摘要：
  - 返回行数。
  - 执行耗时。
  - SQL 安全风险等级。
  - SQL 语句类型。
- 结果区空状态从单行“暂无结果”改为正式引导：
  - 告诉用户需要选择连接并运行 SQL。
  - 说明结果、耗时、安全风险和性能提示会在这里展示。

## 设计原则

- 不改变现有 SQL 执行和导出流程。
- 让用户在中间工作区即可判断当前执行环境，不依赖底部状态栏。
- 保持高信息密度，避免占用过多编辑器空间。

## 验收点

- 编辑器区域能显示当前文件、连接、保存状态和只读状态。
- SQL 执行后，结果表格上方显示行数、耗时、风险、语句类型。
- 未执行查询时，结果区显示可理解的空状态说明。
- 中英文界面均有完整文案。
