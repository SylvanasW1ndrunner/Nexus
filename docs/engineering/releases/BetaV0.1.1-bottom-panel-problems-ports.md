# BetaV0.1.1 底部问题与端口面板

## 背景

底部面板已经具备查询结果和真实终端，但 `问题`、`端口` 两个标签此前仍是禁用占位。对于一个正式 IDE 外壳，可见标签不应不可点击，否则用户会认为功能未完成或界面失效。

## 修复内容

- 底部面板类型扩展为：
  - `problems`
  - `results`
  - `console`
  - `ports`
- `问题` 标签改为可切换真实面板。
- `端口` 标签改为可切换真实面板，并展示明确空状态。
- 新增 `bottom-panel.ts`，集中管理工作台诊断规则。
- 问题面板当前覆盖：
  - SQL 文件为空。
  - SQL 运行前未选择连接。
  - 已选择连接但未连接。
  - 当前文件有未保存改动。
  - 最近一次查询被拦截。
  - 最近一次查询存在性能提示。

## 设计原则

本轮不伪造尚未实现的调试服务器或端口转发能力。`端口` 面板提供稳定入口和空状态，后续接入本地服务探测、端口转发或数据库隧道时复用同一面板。

## 测试覆盖

- `bottom-panel.test.ts` 覆盖 SQL 初始问题、断开连接状态、查询拦截原因和性能提示。
- `i18n.test.ts` 继续覆盖中文文案完整性，避免新增 UI 文案绕过翻译层。
