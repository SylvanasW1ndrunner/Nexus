# BetaV0.1.1 Python 输出终端真实会话修正

## 背景

Python 脚本运行结果会显示在底部终端面板中。终端面板既用于展示脚本输出，也用于用户继续输入项目命令，因此输出目标必须绑定真实终端会话，不能只创建前端临时显示状态。

## 本次实现

- 新增 `selectTerminalOutputTarget`，统一选择脚本输出应该写入的真实终端。
- Python 运行时优先写入当前活跃终端；如果当前活跃终端不存在，则写入第一个真实终端。
- 当用户关闭所有终端后再运行 Python，会先通过主进程创建真实终端会话，再写入 Python 命令和输出。
- 移除 Python 输出路径中创建前端假终端的行为，避免后续输入命令时找不到主进程终端会话。

## 用户体验约束

- Python 输出必须出现在底部终端面板，且用户能继续在同一终端里运行命令。
- 关闭所有终端不是错误状态，运行脚本时 IDE 应自动恢复一个可用终端。
- 输出目标选择必须容忍失效的活跃终端 ID，避免 UI 状态滞留影响脚本执行体验。

## 测试覆盖

- `terminal-layout.test.ts` 覆盖脚本输出目标选择。
- 验证存在活跃终端时选择活跃终端。
- 验证活跃终端失效时回退到第一个真实终端。
- 验证没有终端时返回空目标，由应用层负责创建真实终端。
