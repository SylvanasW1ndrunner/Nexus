# BetaV0.1.1 保存 SQL 弹窗优化

## 背景

BetaV0.1.1 已经把 SQL 保存到项目 SQL 库，但此前保存名称仍通过系统 `window.prompt` 输入。这个原生弹窗无法展示项目上下文，也破坏了桌面 IDE 的一致体验。

## 本次实现

- 将保存 SQL 从系统 prompt 改为应用内弹窗。
- 保存弹窗展示：
  - SQL 名称。
  - 当前项目。
  - SQL 库目录。
  - 当前连接。
  - 当前文件。
- 所有顶部、编辑器工具栏和文件菜单的保存入口都复用同一弹窗。
- 保存确认后仍调用既有 `workspace:save-sql-file` IPC，不改变主进程保存边界。

## 设计原则

- 保存 SQL 是项目管理核心动作，应带有项目上下文。
- 不在 renderer 里拼接保存路径，仍由主进程根据 Workspace 配置决定路径。
- 避免系统原生弹窗打断商业化界面体验。

## 验收点

- 点击保存 SQL 不再出现系统 prompt。
- 已打开项目时显示应用内保存弹窗。
- 弹窗能看到项目、SQL 库、连接和当前文件。
- 保存后文件树可以继续刷新并高亮当前文档状态。
