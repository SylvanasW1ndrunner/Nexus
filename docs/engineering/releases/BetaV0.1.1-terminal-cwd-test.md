# BetaV0.1.1 终端工作目录验证记录

## 背景

终端是数据工程 IDE 的基础能力。用户打开项目后，后续 Python 脚本、SQL 工具、依赖安装和命令行操作都依赖终端工作目录正确。如果终端启动目录错误，用户会在运行脚本、读取相对路径文件、安装依赖时遇到不稳定行为。

## 本次补强

- 为 `TerminalService` 增加真实 PTY 场景测试。
- 测试会创建临时项目目录，并用该目录作为交互式终端的 `cwd`。
- 测试向真实 shell 输入：
  - Windows: `cd`
  - Linux/macOS: `pwd`
- 等待终端输出包含该临时目录，并校验终端会话元数据中的 `cwd`、`name`、`status`。

## 覆盖意义

该测试不是简单 mock，而是验证真实 shell 会话：

- `node-pty` 能按指定目录启动。
- 交互式输入能写入 shell。
- 输出轮询能读取 shell 返回内容。
- 终端会话元数据能保持项目目录信息。

这为后续“打开项目后终端默认落在项目目录”提供了底层保证。
