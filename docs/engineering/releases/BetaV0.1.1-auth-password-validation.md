# BetaV0.1.1 认证表单密码校验

## 背景

认证服务端已经要求注册和重置密码的新密码至少 8 位，但前端表单此前只判断密码非空。用户可能填写短密码并提交，最后由后端报错，体验不符合正式产品登录注册流程。

## 本次调整

- 新增 `isValidNewPassword` 表单规则。
- 注册和忘记密码的新密码必须至少 8 位才允许提交。
- 账号密码登录仍只要求账号和密码非空，保留本地测试账号 `test / test` 的可用性。

## 测试

- `auth-form.test.ts` 覆盖注册、重置密码短密码禁用。
- 覆盖本地测试账号短密码登录仍可提交。

## 验收要点

- 注册和重置密码时，短密码不会进入后端请求。
- 测试账号 `test / test` 仍可用于本地验收登录。
