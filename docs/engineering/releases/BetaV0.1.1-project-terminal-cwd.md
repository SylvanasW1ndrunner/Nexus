# BetaV0.1.1 项目终端工作目录接入记录

## 背景

用户打开或创建项目后，终端应默认服务于当前项目。数据工程师常在终端中安装依赖、运行 Python 脚本、执行项目命令，如果终端仍停留在应用启动目录，会导致相对路径、虚拟环境、输出目录等行为不符合预期。

## 实现内容

- `createTerminal` 支持显式传入 `cwd` 和 `name`。
- 创建项目成功后，立即创建一个以项目根目录为工作目录、项目名为名称的终端。
- 打开项目成功后，同样创建项目目录终端。
- 保留原有行为：手动新建终端时，如果已有项目，则仍使用当前项目根目录作为默认 `cwd`。
