# BetaV0.1.1 IDE 设置页文案细化

## 背景

IDE 设置页已经具备真实持久化能力，编辑器字体、字号、Tab、自动换行、缩略图、行号以及终端字体等配置会保存并在运行时应用。但设置页仍有部分硬编码文案和过时提示，例如“测试版固定默认值”、`Tab Size`、`Minimap` 等，不符合中文默认界面和正式 IDE 体验。

## 本次实现

- 更新编辑器设置说明，明确这些配置会影响代码字体、字号、换行、缩略图和行号显示。
- 为密度、浅色主题、Tab 大小、自动换行、缩略图、行号、默认 shell 占位提示补充 i18n 键。
- 将设置页对应硬编码文案替换为 `t(...)`。

## 用户体验约束

- 中文模式下，IDE 设置页不应出现硬编码英文或过时测试版提示。
- 编辑器设置必须表达真实可用能力，不能暗示配置尚未生效。
- 英文模式仍保留对应英文文案。

## 测试覆盖

- `i18n.test.ts` 覆盖编辑器设置说明、密度选项、Tab、自动换行和行号文案。
- 继续复用 `ide-settings-store.test.ts` 验证设置持久化和范围归一化。
