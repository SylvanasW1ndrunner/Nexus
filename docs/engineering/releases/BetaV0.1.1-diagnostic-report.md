# BetaV0.1.1 诊断报告脱敏合同

## 范围

本次切片新增 `core-tools` 诊断报告生成能力，不涉及前端 UI。

新增能力：

- 生成包含 manifest、配置、日志和崩溃快照的诊断报告文件列表。
- 自动脱敏 API key、Bearer token、密码、token、secret。
- 自动脱敏 SQL / query 字段和日志中的 SQL 片段。
- 支持 7 天日志保留窗口。
- 支持单条内容大小上限，超大日志保留尾部错误上下文。
- 清理报告内路径，避免暴露绝对路径结构中的盘符和 `..`。

## 用户场景

用户遇到远程数据库连接失败、Agent 中断、Python 环境异常或应用崩溃时，后续主进程可以把近期日志和配置传给该模块，生成可附带反馈的脱敏报告。

当前模块输出可打包文件列表；zip 写入、日志目录扫描和入口 IPC 由后续主进程切片接入。

## 测试

已覆盖：

- 应用版本和运行时信息写入 manifest。
- 配置、日志和崩溃快照被收集并脱敏。
- API key、Bearer token、密码和 SQL 内容不会出现在报告里。
- 超出保留窗口的旧日志被忽略。
- 未知日期日志保留。
- 超大日志保留尾部。

## 打包影响

无新增依赖。当前不引入 zip 库，也不增加 native 模块。后续如果接入 zip，需要单独评估依赖大小、许可证和 Electron 打包影响。
