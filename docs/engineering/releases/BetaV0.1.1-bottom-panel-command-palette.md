# BetaV0.1.1 底部面板命令面板入口

## 背景

`问题`、`输出`、`终端`、`端口` 已经成为底部真实面板。IDE 用户通常会通过命令面板快速打开这些面板，因此仅靠鼠标点击底部标签不完整。

## 修复内容

- 新增底部面板命令：
  - 显示问题
  - 显示输出
  - 显示终端
  - 显示端口
- `显示终端` 会复用现有 `openTerminalPanel` 流程：如果没有终端会话，会创建一个真实终端。
- 新增 `bottom-panel-command.ts`，集中管理命令 ID 到底部面板动作的映射。
- 命令面板不再只覆盖侧栏和设置，也能打开工作台底部核心面板。

## 测试覆盖

- `bottom-panel-command.test.ts` 覆盖四个核心命令映射。
- `bottom-panel.test.ts` 继续覆盖问题面板诊断规则。
- `i18n.test.ts` 继续覆盖新增中文命令文案。
