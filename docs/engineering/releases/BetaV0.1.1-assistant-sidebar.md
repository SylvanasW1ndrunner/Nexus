# BetaV0.1.1 右侧助手侧栏优化

## 背景

右侧对话区是数据工程师和分析师与工作台交互的主要入口。BetaV0.1.1 阶段虽然还没有接入完整 Agent 执行链路，但界面需要先具备正式产品的上下文感和可用入口，避免看起来只是一个普通聊天框。

## 本次实现

- 助手上下文增加当前文件类型，便于用户确认助手将围绕 SQL、Python 或文档进行分析。
- 增加快捷问题入口：
  - 解释当前 SQL。
  - 优化当前查询。
  - 生成 Python 数据处理脚本方案。
- 查询历史从斜杠分隔文本升级为结构化标签：
  - 执行状态。
  - 风险等级。
  - 执行耗时。
  - 执行时间。

## 设计原则

- 当前阶段不伪造 Agent 执行能力，只提供可点击的输入草稿入口。
- 快捷问题围绕产品核心业务：SQL 分析、SQL 优化、Python 数据处理。
- 历史记录保持可扫描，便于用户快速回到一条历史 SQL。

## 验收点

- 右侧助手上下文显示项目、连接、当前文件、文件类型。
- 点击快捷问题会把对应问题填入输入框。
- 查询历史展示状态、风险、耗时、时间标签。
- 中英文界面均有完整文案。
