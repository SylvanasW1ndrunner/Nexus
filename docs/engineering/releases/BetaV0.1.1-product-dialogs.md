# BetaV0.1.1 产品内确认弹窗

## 背景

桌面 IDE 不应该在核心工作流中弹出浏览器/系统原生 `confirm` 或 `alert`。这些弹窗样式割裂，也无法承载 SQL 风险说明、文件路径等上下文信息。

## 实现内容

- 新增通用 `ConfirmDialog`，复用现有 modal 样式。
- 替换以下原生确认：
  - 删除数据库连接。
  - 执行需要二次确认的高风险 SQL。
  - 删除项目文件。
  - 删除项目文件夹。
- Python venv 目录选择越界时，不再使用 `window.alert`，改为在 Python 配置表单内展示错误提示。
- 删除和高风险 SQL 使用 danger 视觉状态，确认按钮与普通保存按钮区分。

## 用户影响

- 危险操作确认不再跳出产品界面。
- SQL 风险 detail 和文件路径以等宽文本区域展示，便于用户确认目标。
- 项目设置里的 venv 路径错误能留在当前上下文中，用户不用关闭系统弹窗后再寻找问题来源。

## 验证

- 静态扫描确认 renderer 中不再存在 `window.confirm` / `window.alert`。
- TypeScript 覆盖新增确认弹窗状态类型和翻译键。
- ESLint 覆盖确认回调拆分后的函数签名。
