# BetaV0.1.1 Agent 输出安全层

## 变更摘要

- 新增 `core-agent` 输出安全模块。
- 工具结果、模型最终回复、流式响应、评测报告、报告 store 全链路脱敏。
- 工具执行记录新增 `redacted` 和 `redactionReasons` 证据。
- `core-tools` 业务评测新增合法聚合请求下的 PII 泄漏防护场景。

## 用户价值

数据分析任务常见情况是用户只要求汇总，但底层 SQL 或工具返回了行级客户信息。本切片保证这些结果不会直接进入 Agent 上下文、最终回复或评测报告，同时保留可用的聚合信息，降低真实业务测试和后续生产使用中的数据泄漏风险。

## 验证记录

本切片已通过 core-agent 和 core-tools 的类型检查、lint、目标单元/集成测试、全包回归，以及本地真实 PostgreSQL 门禁。

## 已知限制

- 当前为默认脱敏策略，不是 hard block。
- 当前规则是启发式文本/字段规则，后续应结合 schema semanticType 和字段权限。
- 未新增第三方依赖，打包风险低。
