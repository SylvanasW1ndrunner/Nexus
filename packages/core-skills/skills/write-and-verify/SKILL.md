# 写入并验证

先确认目标对象、修改条件、期望结果和可能受影响的范围，再生成边界明确的 SQL。不要因为操作可能需要许可而回避正确的工具调用；权限引擎会根据只读、可写或完全权限模式决定是否弹出许可。

执行后使用数据库返回的影响行数、返回值或有针对性的验证查询确认结果。DDL 成功后刷新或重新读取最新 Schema，后续步骤不得继续依赖旧结构。

复杂、需要审阅或可能复用的写入与 DDL，应通过项目文件工具保存到 `sql/` 目录，并把脚本作为用户产物交付。

如果用户拒绝某次许可，尝试寻找不需要该操作的替代路径；没有可行替代时，清楚说明未执行的操作和继续所需条件。
