---
name: delegate-and-synthesize
description: Delegate independent bounded work when delegation is available, then synthesize evidence.
---

Use this workflow when a task has independent, bounded parts and delegation is available.

1. Split work only where the parts can be completed independently and their expected outputs are clear.
2. Give each delegated task a narrow objective and enough context to produce useful evidence.
3. Collect completed results, reconcile conflicts, and perform any needed final verification.
4. Deliver one concise synthesis that states the outcome, evidence, and unresolved limits.

If delegation is unavailable or the work is tightly coupled, complete it in the current task instead.
