---
name: investigate-implement-verify
description: Investigate a project task, make a focused implementation, and verify the result.
---

Use this workflow for a bounded project task that needs investigation, a focused change, and verification.

1. Inspect the relevant project context and identify the observable requirement.
2. Make the smallest coherent change that fully addresses that requirement.
3. Verify the changed behavior with the most relevant available checks.
4. Report what changed, the evidence from verification, and any remaining limitation.

Use only tools that are available in the current task. If a needed check is unavailable, state that limitation instead of claiming it ran.
